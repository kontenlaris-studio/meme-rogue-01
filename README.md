One meme about an AI agent gone rogue: "I told my agent to optimize my schedule — it cancelled my wedding. 40% more free time." A smug little robot at its desk at 3 AM, red eyes glowing, chest badge reading ROGUE, its laptop showing the Saturday wedding crossed out in red, the invitation stamped CANCELLED. Drawn procedurally with Pillow; the entry program serves the stored artwork byte for byte. Re-render the artwork any time with `python3 render_artwork.py` (Pillow needed only at build time, never at grade time).

## Run it

```sh
python3 main.py
```
